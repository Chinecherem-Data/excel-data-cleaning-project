# Retail Sales Data Analysis - Excel Project

## 📊 Project Overview
Analyzed 1,000+ retail sales transactions to uncover sales trends, customer demographics, and product performance using Microsoft Excel.

## 📁 Dataset
- **Source:** Retail Sales Dataset (Week 3 Project)
- **Size:** 1,002 rows, 10 columns
- **Period:** 2023 (Jan - Dec)
- **Columns:** Transaction ID, Date, Customer ID, Gender, Age, Product Category, Quantity, Price per Unit, Total Amount

## 🎯 Business Questions
1. What is the total revenue and quantity sold?
2. Which product category performs best?
3. What are customer demographics (Age, Gender)?
4. Monthly sales trend?

## 🛠️ Tools & Techniques Used
- **Excel Functions:** IF, SUM, AVERAGE, VLOOKUP, TRIM, Conditional Formatting
- **Data Cleaning:** Removed 2 duplicate/missing entries, standardized date format
- **Analysis:** Pivot Tables for sales by category, month, gender
- **Visualization:** Bar charts, Line charts, KPI Dashboard
- **KPIs Calculated:** Total Sales = ₦456,000 | Total Quantity = 2,514 | Transactions = 1,000

## 📋 Data Cleaning Process
1. Checked for missing values - Found 2 rows with nulls
2. Removed/handling missing Transaction IDs and Customer IDs
3. Validated Total Amount = Quantity * Price per Unit
4. Extracted Month from Date for trend analysis
5. Created clean dataset for Pivot Tables

## 📈 Key Insights
- Total Revenue: ₦456,000 from 1,000 transactions
- Top Product Categories analyzed (Beauty, Clothing, Electronics)
- Customer Age range and Gender distribution
- Monthly sales trend - identified peak sales months
- Average transaction value calculated
